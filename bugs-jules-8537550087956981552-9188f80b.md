### [ISSUE-01] Plan Editor Updates Silently Drop Edited Days, Exercises, and Sets
- **Severity:** High
- **File:** `apps/workout/frontend/src/app/[locale]/plans/[planId]/page.tsx:28`
- **Category:** Logic / Performance
- **Description:** When editing an existing workout plan on the plan detail page, `handleSave` receives the full `PlanCreate` payload (which includes `days`, `exercises`, and `sets` modified in `PlanEditor`), but only invokes `updatePlanMutation.mutateAsync({ name, description, is_shared })`. As a result, any modifications to days, exercises, or target sets made in the plan editor when editing an existing plan are silently discarded and never saved to the backend.
- **Current Code:**
  ```tsx
  const handleSave = async (payload: PlanCreate) => {
    try {
      await updatePlanMutation.mutateAsync({
        name: payload.name,
        description: payload.description,
        is_shared: payload.is_shared,
      });
      router.push("/plans");
    } catch (err) {
      console.error("Failed to update plan:", err);
    }
  };
  ```
- **Suggested Fix:** Update the plan detail save handler or backend API integration to sync days, exercises, and set modifications (via granular day/exercise/set mutation endpoints or extended plan update endpoint) when editing an existing plan.
- **Status:** [x] Closed
